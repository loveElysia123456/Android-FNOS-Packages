# 飞牛 fnOS 应用

## GyroView 全景素材查看器

在浏览器查看飞牛 NAS 上的影石 INSV 原片和 LRV 全景预览。适用于 x86_64、fnOS 1.2.0401 或更新版本，需要可用的 Python 3 运行环境。

| 版本 | 飞牛安装包 | 更新说明与源码 |
| --- | --- | --- |
| v1.0.1 | [下载 FPK](https://github.com/loveElysia123456/Android-FNOS-Packages/releases/download/gyroview-v1.0.1/gyroview-fnos-v1.0.1.fpk) | [恢复 LRV 到 INSV 原片的入口](https://github.com/loveElysia123456/Android-FNOS-Packages/releases/tag/gyroview-v1.0.1) |
| v1.0.0 | [下载 FPK](https://github.com/loveElysia123456/Android-FNOS-Packages/releases/download/gyroview-v1.0.0/gyroview-fnos-v1.0.0.fpk) | [首个公开版本](https://github.com/loveElysia123456/Android-FNOS-Packages/releases/tag/gyroview-v1.0.0) |

在飞牛应用中心选择「手动安装」，上传 FPK，安装后授权素材目录。如果授权后仍无法读取，停用再重新启用应用。
