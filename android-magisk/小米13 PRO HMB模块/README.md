# 小米13 PRO HMB模块

用于小米 13 Pro（nuwa）国产替换屏的强光高亮度限制。作者 loveElysia。

| 版本发布页 | 分支 | 附件 |
| --- | --- | --- |
| [v0.1.1](https://github.com/loveElysia123456/Android-FNOS-Packages/releases/tag/nuwa-hbm-cap-v0.1.1) | LSPosed 历史版 | 模块 ZIP、修订管理 APK，源码暂缺 |
| [v0.1.2-test1](https://github.com/loveElysia123456/Android-FNOS-Packages/releases/tag/nuwa-hbm-cap-v0.1.2-test1) | LSPosed 历史测试版 | 模块 ZIP、管理 APK、源码 ZIP |
| [v0.2-fix](https://github.com/loveElysia123456/Android-FNOS-Packages/releases/tag/nuwa-hbm-cap-v0.2-fix) | LSPosed 版 · 默认 480 nit | 模块 ZIP、管理 APK、源码 ZIP |
| [v0.2NOLSP-fix](https://github.com/loveElysia123456/Android-FNOS-Packages/releases/tag/nuwa-hbm-cap-v0.2nolsp-fix) | 独立版 · 默认 450 nit | 模块 ZIP、源码 ZIP |

- **LSPosed 版**安装模块 ZIP 后，安装同版本管理 APK，启用 LSPosed 的系统框架作用域，再重启。ZIP 内的 APK 与独立下载的 APK 一致。
- **NOLSP 版**单独安装 ZIP，通过模块「执行」和音量键调节。全局上限也可能影响手动亮度和 HDR。禁用或卸载前，先在「执行」中同时按住两个音量键恢复原配置。
- 两个分支择一安装。fix 文件对应的包内版本分别为 `0.2`（内部版本号 6）与 `0.2NOLSP`（内部版本号 7）。强光下指纹表现仍待真机验证。
